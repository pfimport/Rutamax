# Sistema de Comisiones PF

Calculador de comisiones para vendedoras con integración a Xubio.

## Instalación (Windows)

1. Descargá este repositorio como ZIP (botón verde `Code` → `Download ZIP`)
2. Extraé el ZIP en cualquier carpeta de tu PC
3. Doble clic en **`INSTALAR.bat`** (solo la primera vez)
4. Doble clic en **`INICIAR.bat`** para usar el sistema

## Uso diario

- Doble clic en **`INICIAR.bat`** → el sistema se abre en el navegador
- **No cierres** la ventana negra mientras usás el sistema

## Primer uso

Al abrir el sistema por primera vez, ir a la pestaña **Configuración** y cargar las credenciales de la API de Xubio (Client_id y Secret_id).
